# Wake-on-LAN Sparrechner

Interaktive Abschätzung, wie viel Strom, Kosten und CO₂ ein Bürogebäude pro Jahr spart, wenn PCs außerhalb der Arbeitszeit schlafen dürfen und per Wake-on-LAN nur bei Bedarf geweckt werden.

**Live:** https://fbw159.github.io/wol-sparrechner/

- Alle Annahmen (Mitarbeitende, Arbeitszeit, Fernzugriff, Leistung im Leerlauf/Ruhezustand, Strompreis, CO₂-Faktor) lassen sich ändern.
- Startwerte und Quellen stehen auf der Seite selbst.
- Eigene Werte speichert nur der eigene Browser (localStorage), es werden keine Daten übertragen.

Eine einzelne HTML-Datei ohne Build-Schritt.
